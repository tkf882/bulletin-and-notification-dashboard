GET /posts/type?pid=#&sort=#

Description

Returns all posts if authenticated by middleware

Requires the 'Authorization' header with a token

  • type - "all" will get all posts. "comments" will get comments with parent=pid
  • pid - Query with pid = #
  • sort - Sort order = # (type = "all" only)
    • 0: Date (Desc)
    • 1: Date (Asc)
    • 2: Title (Desc)
    • 3: Title (Asc)

Response

  "pid":1,
  "user_id":1,
  "username":"sisyphus",
  "title":"Hello, my name is sisyphus",
  "content":"This is my first post.",

  "date":"18:06:35 - 19/03/2026",
  "status":1,
  "parent":null
},{

POST /posts

Description

Create a new post. Include a body with a title, content, username, parent, and tagString.

If the parent is not null but rather a pid, then it is a comment on that post with pid.

Requires the 'Authorization' header with a token

Request

{
  "title": "this is the title",
  "content": "this is the post content",
  "username": "sisyphus",
  "parent": null,
  "tagString": "Intro,Announcement"
}

Response

{
  "pid": 2,
  "message": "Post success"
}
